# Как редактировать сайт самому

Три уровня: от простого к удобному.

## 1. Админка у себя на компьютере (тексты, картинки, теги)

1. Один раз в папке проекта:
   ```bash
   npm install
   ```
2. Запустить сервер:
   ```bash
   npm run dev
   ```
3. Открыть http://localhost:5173/keystatic/ (слэш в конце обязателен). Дальше «Новости» → «Создать» или выбрать существующую.
4. Кнопка **Save** записывает файлы в проект. На сайт они ещё не попали.
5. Чтобы выложить на стенд, нужен пуш. Проще всего через [GitHub Desktop](https://desktop.github.com): открыть в нём папку проекта, нажать **Commit to main**, затем **Push origin**. Через 2–3 минуты стенд обновится.

Подробно про поля: [CONTENT.md](CONTENT.md).

## 2. Правки в вёрстке и коде

- Через Claude: описать, что поменять, он правит файлы и пушит.
- Самому: открыть папку в VS Code, править файлы в `src/styles`, `src/components`, `src/pages`. На `npm run dev` сайт обновляется сразу при сохранении. Перед пушем запустить `npm test`.

## 3. Без компьютера, через браузер GitHub

Открыть файл новости в `src/content/news/` на GitHub, нажать карандаш, изменить текст, сохранить кнопкой **Commit changes**. Стенд пересоберётся сам. Подходит для мелких правок текста; картинки и теги так добавлять неудобно.

## Чего пока нельзя

Править через админку с телефона или чужого компьютера. Для этого Keystatic переключается в режим GitHub (`storage.kind: 'github'`), а сайт переезжает на хостинг с сервером (Vercel, Netlify или Cloudflare). Тогда админка будет по адресу вроде `сайт/keystatic`, вход через GitHub, а Save сам делает коммит. Делается, когда тестовый стенд устроит.
