# Как заполнять сайт

Для редактора. Всё происходит в админке: `npm run dev`, затем http://localhost:5173/keystatic/.

## Новость

**Новости → Создать.**

| Поле | Что писать |
|---|---|
| Заголовок | Суть в одной фразе, до 90 символов |
| Адрес (латиницей) | Часть ссылки: `/news/<адрес>/`. Подставляется сам, поправьте на понятный. После публикации не меняйте |
| Лид | 1–2 предложения: главное. Попадает в описание для Google и Яндекса и в соцсети |
| Дата публикации | Ставится сама. Время редакции (Минск) |
| Обновлено | Заполните, когда правите опубликованный материал: покажется на странице и в поиске |
| Раздел | Один из восьми пунктов меню |
| Теги | 1–3 тега. Если нужного нет, сначала создайте в «Теги» |
| Обложка | Желательно 16:9, ширина от 1200 px. Остальное сайт сделает сам |
| Коротко и по делу | 3 пункта: суть материала. Идут в блок «Коротко и по делу» под обложкой (удобно людям и нейросетям) |
| Узкая карточка справа | Только у одной новости. В ленту она не попадает |
| Черновик | Пока стоит галочка, на сайт не попадает |
| Текст | Основной текст, см. ниже |

## Текст

Обычное оформление: заголовки (только `##`, второй уровень), абзацы, списки, ссылки. Кнопка **+** вставляет блоки:

- **Галерея**: несколько фото со счётчиком и подписями; открывается на весь экран с зумом.
- **Картинка на всю ширину**: фото с подписью.
- **Цитата с источником**: текст цитаты и «Кто сказал / где опубликовано» + ссылка на источник.
- **Список с галочками**: внутри обычный маркированный список.

Правила, которые помогают поиску и нейросетям:
- Начинайте с главного: первые две фразы отвечают на «что случилось».
- Для каждого фото заполняйте описание (alt): коротко, что на картинке.
- Цифры и даты пишите явно, у цитат указывайте источник со ссылкой.
- Сильно меняете материал: заполняйте «Обновлено».

## Страницы и настройки сайта

В меню админки слева, кроме новостей и тегов, есть три раздела.

**Главная.** Заголовок справа от ленты, вступление (пустая строка между абзацами делит текст на абзацы) и «Закреплённая новость»: она всегда первая в ленте. Если поле пустое, лента идёт по дате.

**О проекте.** Заголовок, лид, «Коротко и по делу» и текст с обычным редактором. Заголовки «Контакты», «Реклама» и «Предложить новость» не переименовывайте: на них ведут ссылки в боковом меню.

**Настройки сайта.** Название, title и описание для поисковиков, почта редакции, автор по умолчанию, ссылки на соцсети и текст в подвале. Пока ссылка на соцсеть пуста, в меню остаётся заглушка; заполненные адреса попадают и в разметку для поисковиков.

## Баннер справа

У каждой статьи в поле «Баннер справа» можно выбрать новость, которая показывается справа (на экранах от 1600px). Если пусто, баннер подбирается автоматически: очки за общие теги (по 3) и тот же раздел (2), при равенстве выше свежая; саму статью и материалы из «Читайте также» не берём. Если подходящих нет, показывается новость с галочкой «Баннер по умолчанию» (ставьте её только у одной новости). На главной и страницах списков всегда баннер по умолчанию.

## Тег

**Теги → Создать.** Название (как показывать), адрес латиницей (часть ссылки `/tag/<адрес>/`) и описание страницы тега: 1–2 предложения о том, что собрано в теге.

## Что куда попадает

- Новость появляется в ленте на главной (8 на странице, остальное в архиве `/news/page/2/`), в своём разделе и на страницах тегов.
- В поиск (Ctrl+K), в `rss.xml`, в `sitemap` и в `llms.txt` она попадает автоматически.
- «Итоги недели» собираются из новостей за неделю; новая неделя добавляется в `src/data/site.ts` (`DIGESTS`).

## Сохранение

Кнопка **Save** записывает файлы в проект (`src/content`, `src/assets`). Дальше правки нужно закоммитить: на тестовом стенде GitHub Pages сайт пересоберётся сам после пуша в `main`.
